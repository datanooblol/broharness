# Knock-knock jokes

A knock-knock joke is built entirely on its call-and-response structure -- the
punchline only lands because of the back-and-forth, not the words alone.

## Characteristics

- Fixed structure: "Knock knock." / "Who's there?" / "[Name]." / "[Name] who?" /
  punchline that turns the name into a pun or unexpected phrase when said aloud.
- The punchline usually works because the name sounds like a word or short
  phrase when spoken quickly (a homophone gag, same idea as a pun but delivered
  through the call-and-response instead of a single line).
- Very short -- there's no room for a long setup, the structure does the work.
- Works best read as dialogue, not as a single paragraph -- keep the exchange format.

Use this as a style guide to write a fresh, original knock-knock joke on the
requested topic -- not a script to copy from verbatim.
