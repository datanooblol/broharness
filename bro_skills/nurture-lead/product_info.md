# Product info (mock)

BroFlow Suite is a small-team workflow automation tool.

- **Who it's for**: teams of 1-50 people who want to automate repetitive
  multi-step tasks without writing infrastructure code.
- **Core features**: visual flow builder, scheduled triggers, integrations
  with common chat/email tools, per-step audit logging.
- **Plans**: `starter`, `pro`, and `enterprise` (see pricing, handled by the
  present-offer stage — this file intentionally has no prices in it).
- **Support**: email support on all plans, priority chat support on `pro`
  and `enterprise`.
