# Puns

Puns rely on wordplay -- a word or phrase that sounds like another, or carries
two valid meanings, used so the double meaning lands as a surprise at the end.

## Characteristics

- Built on a homophone, homograph, or near-sound-alike word pair.
- Usually has a short setup that reads normally right up until the punchline
  reveals the double meaning.
- Can be cleverer or more layered than a dad joke -- the surprise of the wordplay
  is the point, not just its corniness.
- Works on any topic -- not tied to one subject, so it fits whatever topic the
  user asked for.

Use this as a style guide to write a fresh, original pun on the requested topic
-- not a script to copy from verbatim.
